# Repository instructions

## Language and punctuation

- Never use the em dash character (Unicode U+2014) in responses, code, comments,
  documentation, pull request descriptions, commit messages, or other text. Use
  simple punctuation instead.
- All repository code, identifiers, comments, program output, documentation,
  scripts, tests, configuration explanations, and other maintained textual
  content must be in English. This applies to the complete repository, not only
  new changes. Audit existing content when maintaining it.
- Conversation replies may remain in the user's language.
- Preserve the exact bytes of external evidence, signatures, cryptographic
  material, and deliberate test inputs when their integrity is required. Explain
  such data in English; do not silently rewrite evidence.
